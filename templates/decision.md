# DEC-ID Decision Title

## Question

State the decision the human needs to make in one sentence.

## Options

### Option 1: Short label

Tradeoffs: cost, risk, and what choosing this forecloses.

### Option 2: Short label

Tradeoffs: cost, risk, and what choosing this forecloses.

## Recommendation

Option N. Two or three sentences with evidence links explaining why. A
decision without a recommendation forces the human to redo the analysis;
always include one unless the options are genuinely symmetric.

## Default If No Response

If there is no response by RESPOND-BY-DATE, work proceeds as Option N.

The default may never include accept, merge, push, deploy, spend, credential
creation, or any other human-gated action. If every safe path requires a
human, the default is "linked work pauses".

## Evidence

Link the reports, tickets, data, or external sources the options rest on.

## Outcome

Appended automatically by `palari decide record DEC-ID --choice N --by NAME`.
Only a human records an outcome.
