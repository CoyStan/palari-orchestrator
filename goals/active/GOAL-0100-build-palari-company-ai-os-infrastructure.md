# GOAL-0100 Build Palari company AI OS infrastructure

## Why

Palari is evolving from repo-native AI coding governance into the
infrastructure for company-level AI-governed work. This goal keeps that
expansion anchored in the existing Palari boundary: repo artifacts, explicit
human authority, evidence, review, and fail-closed behavior.

## Success Criteria

- Palari can model workflows, human governance load, human skill coverage, autonomy ceilings, policy simulation, brokered evidence, and outcomes without bypassing human authority

## Boundaries

- This goal does not authorize real external side effects.
- This goal does not authorize silent autonomous acceptance.
- This goal does not replace human accountability with policies or agents.
- This goal does not create a hosted service or generic agent framework.
