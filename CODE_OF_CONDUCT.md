# Code Of Conduct

Palari Orchestrator welcomes direct, technical criticism delivered with basic
respect.

Expected behavior:

- be specific about bugs, risks, and tradeoffs
- assume good intent while still checking claims
- keep security reports private until a fix path exists
- avoid harassment, threats, personal attacks, and identity-based abuse

Maintainers may remove disruptive behavior from project spaces. For private
concerns, contact the maintainer through the repository owner profile.
